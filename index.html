qrcp: Transfer files over wifi from your computer to your mobile device by scanning a QR code without leaving the terminal.

Free & open source · MIT
No app on the phone, no cloud, no accounts.

$ qrcp holiday-photos.zip
Scan the following URL with a QR reader to start the file transfer, press CTRL+C or "q" to exit:

No app needed

Any phone camera or QR reader works. The transfer happens in the mobile browser.

Both directions

qrcp file sends to the phone, qrcp receive serves an upload page and saves what you pick.

Stays on your network

Files go straight over your local Wi-Fi. Nothing is uploaded anywhere, and the URL is random and one-shot.

Folders & many files

Send whole directories or several files at once; they're zipped on the fly.

HTTPS when you want it

Bring your own certificate for encrypted transfers. See how.

Runs everywhere

A single binary for Linux, macOS and Windows, on Intel and ARM.

Free and open source, for good

qrcp is open-source software released under the MIT license. No ads, no paid tier: the code is all on GitHub for you to read, audit, fork and improve.

  • 10k+ stars on GitHub
  • 50+ contributors

How it works

  1. 1Run qrcp
    It starts a tiny web server on your Wi-Fi address and prints a QR code.
  2. 2Scan it
    Point your phone's camera at the terminal and open the link.
  3. 3Done
    The file downloads (or uploads) and qrcp exits on its own.

Install

brew install qrcp

Linux (Arch)

yay -S qrcp-bin

winget install --id=claudiodangelis.qrcp -e
